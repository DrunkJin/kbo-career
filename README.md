# Baseline Career

드래프트부터 은퇴까지, 야구 선수 한 명의 커리어를 끝까지 살아보는 시뮬레이터입니다.
KBO 퓨처스에서 시작해 KBO · NPB · MiLB · MLB까지 올라가거나, 끝내 1군의 문턱을 넘지 못하고
유니폼을 벗습니다.

## 게임 구조

### 시작
포지션(투수 / 포수 / 내야수 / 외야수)과 이름만 정하면, 시작 구단과 리그가 **무작위로** 결정됩니다.

| 시작 지점 | 확률 |
| --- | --- |
| KBO 퓨처스 | 50% |
| KBO 1군 (1라운드 지명) | 12% |
| NPB 육성선수 | 16% |
| MiLB Double-A | 18% |
| MLB 즉시 데뷔 | 4% |

숨겨진 **잠재력**(62~99)도 이때 함께 정해집니다. 잠재력은 능력치 성장의 상한이며,
등급(S/A/B/C/D)으로만 공개됩니다.

### 한 시즌의 흐름
`스프링캠프 → 전반기 → 후반기 → 시즌 결산 → 오프시즌` 5단계로 진행됩니다.
앞의 세 단계와 오프시즌에서 상황에 맞는 **이벤트**가 하나씩 등장하고, 선택은 되돌릴 수 없습니다.

선택지에는 위험도(안정 / 도전 / 무모)가 붙습니다. 도전·무모 선택지는 가중치 기반 확률로
결과가 갈리며, 성공하면 크게 얻고 실패하면 부상·신뢰 하락 등의 대가를 치릅니다.

### 진행 속도
상단의 **기본 / 빠르게 / 초고속** 으로 직접 고를 이벤트 수를 조절합니다.

| 속도 | 직접 고르는 이벤트 | 시즌당 클릭 |
| --- | --- | --- |
| 기본 | 캠프 · 전반기 · 데드라인 | 약 4회 |
| 빠르게 | 캠프 · 데드라인 | 약 3회 |
| 초고속 | 캠프 | 약 2회 |

건너뛴 이벤트는 **사라지지 않고 자동으로 처리**되어 결과만 뉴스에 남습니다. 이벤트를 통째로
없애면 피해까지 사라져 난이도가 확 낮아지기 때문입니다. 실제로 세 속도의 통산 WAR·은퇴
나이는 통계적으로 같습니다(400회 기준 WAR 42.1 / 42.6 / 42.9).

시즌 중에는 **⏩ 시즌 자동 진행** 버튼으로 남은 이벤트를 한 번에 자동 처리하고 결산까지
건너뛸 수 있습니다.

### 이벤트
총 64종이며, 상황이 구체적인 이벤트일수록 더 자주 등장하도록 가중치가 붙습니다.

- **연차별** — 첫 캠프, 숙소의 밤, 신인왕 레이스, 첫 연봉 협상, 주전 경쟁, 결혼,
  연봉조정 신청, 주장 완장, 통산 기록 도전, 벤치 통보, 코치 제안, 은퇴 투어
- **포지션별** — 투수(새 구종·구속 vs 제구·완투·불펜 전환·노히터), 포수(프레이밍·에이스와의
  마찰·무릎), 내야수(송구 입스·유격수 도전·병살 저지), 외야수(펜스 플레이·중견수 전환·홈 승부)
- **구단별** — KBO 10개 구단과 요미우리·한신·소프트뱅크·양키스·다저스·레드삭스의
  홈구장과 팬 문화를 소재로 한 상황

### 능력치
포지션에 따라 보이는 능력치가 다릅니다.

- **타자** — 컨택, 파워, 선구안, 주루, 수비
- **투수** — 구속, 제구, 구위, 체력
- **공통** — 멘탈, 내구성

OVR은 포지션별 가중치로 계산된 값이며, 능력치가 실제 시즌 성적 계산에 직접 들어갑니다.
(컨택 → 타율, 파워 → 홈런, 제구 → WHIP·ERA, 내구성 → 부상 확률 …)

### 능력치가 성적으로 번역됩니다
`컨택 +2` 같은 숫자는 그 자체로는 와닿지 않습니다. 그래서 능력치가 바뀔 때마다
**그 변화가 성적을 어떻게 바꾸는지** 직접 계산해 보여줍니다.

```
타율      .264 → .278   +.014
홈런        15 → 19       +4
타점        78 → 88      +10
예상 WAR   3.0 → 3.7     +0.7
```

시즌 시뮬레이션과 완전히 같은 공식을 쓰되 난수만 평균값으로 고정해(`projectSeason`)
"운이 중립일 때의 성적"을 뽑습니다. 커리어 탭 상단의 **지금 이대로 풀시즌을 치르면** 카드가
항상 이 예상치를 보여주므로, 능력치 +1이 실제로 무엇을 바꾸는지 눈으로 확인할 수 있습니다.
역할이 바뀌면(백업 → 주전) 그것도 함께 표시됩니다.

### 시즌 성적
소속 리그의 평균 수준과 자신의 능력치 차이로 성적이 결정됩니다.
타자는 타율/홈런/타점/도루/OPS, 투수는 이닝/승패/세이브/ERA/WHIP/탈삼진이 기록되고,
WAR은 **해당 리그의 평균 선수 기준**으로 산출됩니다. 2군에서 잘한다고 명예의전당에 가지는 않습니다.

### 계약과 이적
계약은 연봉 + 연수로 관리됩니다. 계약이 만료되거나 구단 신뢰가 바닥나면 오퍼가 최대 5개 도착합니다.

기본 오퍼는 **잔류 · 승격 · 동급 리그 이적 · 강등**이고, 여기에 리그를 건너뛰는 경로가 붙습니다.

| 경로 | 조건 |
| --- | --- |
| KBO → NPB (포스팅) | OVR 74+ · 직전 WAR 3.5+ |
| KBO → MLB (포스팅) | OVR 78+ · 직전 WAR 3.5+ |
| KBO → AAA (스플릿 계약) | OVR 71+ · 28세 이하 · WAR 2.5+ |
| NPB → MLB (포스팅) | OVR 78+ · 직전 WAR 4+ |
| **NPB → KBO (복귀)** | 28세 이상 · 기량 하락 또는 WAR 3 미만 |
| **MLB → KBO (유턴 대형 계약)** | 28세 이상 · 기량 하락 또는 WAR 2.5 미만 |
| **MLB → NPB (이적)** | 27세 이상 · 리그 평균 +3 미만 |
| AAA → KBO / NPB | 25~26세 이상 |
| AA → KBO | 26세 이상 · OVR 62+ |
| NPB 2군 → KBO | 26세 이상 |
| 퓨처스 → NPB 2군 | 25세 이하 · OVR 58+ |

즉 **올라가는 길과 돌아오는 길이 모두 열려 있습니다.** MLB에서 자리를 잃으면 AAA 강등뿐 아니라
KBO 유턴이나 NPB 이적을 고를 수 있고, 유턴 계약은 시장가의 1.6배로 커리어 최대 연봉이 되기도 합니다.
반대로 잘하고 있는 선수에게는 굳이 하위 리그 오퍼가 오지 않습니다.

- **FA** — KBO 8시즌 / MLB 6시즌 등록 시 자격 획득

### 국가대표
WBC(4년 주기)와 올림픽이 열리는 해에 OVR 70 이상 · 명성 35 이상이면 대표팀 승선 제안을 받습니다.
성적은 메달과 함께 국제대회 전적으로 남습니다.

### 은퇴
나이·능력치·부상·리그 수준을 종합해 은퇴가 결정됩니다. 은퇴 후에는 종합 리포트가 나옵니다.

- 명예의전당 점수(0~100)와 등급 — 리그 수준으로 가중한 WAR, 수상, 우승, 국제대회 메달 반영
- 통산 성적, 시즌별 전 기록, 커리어 하이 시즌
- 수상 내역(MVP / 골든글러브 / 타이틀 / 올스타 / 신인왕 / 우승 반지) 집계
- 국제대회 전적과 메달
- 리그별 발자취, 커리어 연대기
- 요약 텍스트 공유(Web Share API, 미지원 시 클립보드 복사)

## 조작

- `Space` 또는 `Enter` — 다음 단계 진행 / 시즌 결산 닫기
- 진행 상황은 브라우저 `localStorage`에 자동 저장되며, 시작 화면에서 이어할 수 있습니다.
- 모바일에서는 탭 메뉴가 하단 고정 탭바로 바뀌고, 진행 버튼이 화면 아래에 고정되며,
  모달은 바텀시트로 열립니다. 터치 타겟은 48px 이상을 유지합니다.

## 구조

```
src/
  game/
    types.ts             게임 데이터 모델
    data.ts              구단(KBO 10 · NPB 12 · MLB 30) · 리그 정의 · 로고 경로
    engine.ts            능력치/OVR, 시즌 시뮬레이션, 예상 성적, 성장·노쇠, 계약, 커리어 평가
    events.ts            기본 이벤트 + 추첨 로직 (전체 이벤트를 합쳐 export)
    events-career.ts     연차별 이벤트
    events-position.ts   포지션별 이벤트
    events-team.ts       구단별 이벤트
    store.ts             리듀서(게임 상태 머신) · 속도 · 세이브
  components/            화면 단위 컴포넌트
scripts/
  fetch-logos.sh   구단 로고 수집
  sim.ts           밸런스 검증용 헤드리스 시뮬레이션
  impact.ts        능력치 +3 이 성적을 얼마나 바꾸는지 표로 출력
  events-check.ts  이벤트 개수 · 중복 id · 페이즈/타게팅 분포
  smoke.tsx        전 화면 렌더 스모크 테스트 (배포 전 크래시 탐지)
```

## 구단 로고

`img/logo/` 아래에 슬러그 이름으로 저장됩니다. MLB는 공식 CDN(mlbstatic)의 SVG,
KBO·NPB는 Wikipedia에서 받아옵니다. 다시 받으려면:

```bash
bash scripts/fetch-logos.sh          # 이미 받은 파일은 건너뜁니다
NAP=6 bash scripts/fetch-logos.sh    # 위키미디어 레이트 리밋에 걸릴 때 간격을 늘립니다
```

로고는 각 구단의 상표이며, 이 프로젝트에서는 개인 학습·비상업 용도로만 사용합니다.

## 밸런스 검증

리듀서를 그대로 돌려 수백 개의 커리어를 시뮬레이션합니다.

```bash
npx esbuild scripts/sim.ts --bundle --platform=node --format=cjs \
  --define:import.meta.env.BASE_URL='"/"' --outfile=.sim.cjs && node .sim.cjs 400 내야수
```

네 번째 인자로 속도(`normal` / `fast` / `turbo`)를 넘기면 속도별 밸런스를 비교할 수 있습니다.
무한 루프, 리그 도달률, 통산 WAR 분포, 명예의전당 점수 분포, 리그 전환 횟수, 이벤트 등장
빈도를 출력합니다.

다른 점검 스크립트도 같은 방식으로 돌립니다.

```bash
# 능력치 +3 이 성적을 얼마나 바꾸는지
npx esbuild scripts/impact.ts --bundle --platform=node --format=cjs   --define:import.meta.env.BASE_URL='"/"' --outfile=.x.cjs && node .x.cjs

# 전 화면 렌더 크래시 점검
npx esbuild scripts/smoke.tsx --bundle --platform=node --format=cjs --jsx=automatic   --define:import.meta.env.BASE_URL='"/"' --outfile=.x.cjs   && node -e "globalThis.localStorage={getItem:()=>null,setItem(){},removeItem(){}};require('./.x.cjs')"
```

이동 경로가 실제로 열려 있는지만 확인하려면:

```bash
node .sim.cjs routes
```

리그·나이·기량 조합별로 어떤 오퍼가 몇 %로 생성되는지 보여줍니다.
