# Baseline Career

KBO 퓨처스리그에서 시작해 KBO, NPB, MLB 마이너리그와 메이저리그까지 도전하는 야구 선수 커리어 시뮬레이터입니다.

## 로컬 실행

```bash
npm install
npm run dev
```

## GitHub Pages 공개 배포

`main` 브랜치로 푸시하면 GitHub Actions가 자동으로 빌드하고 배포합니다. GitHub 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 한 번만 선택하세요.
