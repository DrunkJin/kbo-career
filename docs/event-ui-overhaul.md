# 이벤트·모바일 개편 (2026-09-13)

197개 이벤트의 본문, 모든 변형, 선택지, 결과와 등장 조건을 함께 검토했다. 기존 이벤트 ID를 유지하면서 내용과 조건을 개편해 저장 호환성을 지켰다.

## 내용과 등장 조건

| 문제 유형 | 적용한 변경 |
| --- | --- |
| 투수가 타격·대타·야수 겸업을 수행 | SSG·보스턴 구장 타격, 중견 연차 수비 경쟁, 베테랑 대타 사건을 타자 전용으로 제한. 공통 팬·가족·여행·훈련·인터뷰·구단 사건의 타석/홈런 결과를 포지션 공통 표현으로 교정 |
| 어린 선수의 오래된 개인 팬 경력 | 오래 구단을 응원한 팬이 최근 선수를 응원하기 시작했다는 편지로 변경. 편지가 아닌 본문에도 답장을 쓰던 변형 불일치 제거 |
| 불펜의 장이닝·선발의 구원 상황 | 노히트노런, 세 번째 타순, 연속 조기 강판은 선발 전용. 구원 등판·불펜 준비는 불펜/마무리 전용. 마무리 공석 제안은 기존 마무리에게 나오지 않음 |
| 팜 선수가 모구단 홈구장에 등장 | 구단 사건 16개와 구단×포지션 사건 64개에 KBO/NPB/MLB 리그 조건 추가. 모구단 이름이 같아도 2군에서는 제외 |
| 장기 재활 중 실전 사건 | 부상 severity 0.5 이상이면 상담·회복·생활 등 명시적으로 허용된 사건만 등장. 선택 가능한 사건은 모든 단계에 유지 |
| 첫 경험 반복 | 첫 캠프·첫 협상·가족 방문·일본 적응·MLB 클럽하우스 적응 등에 커리어 1회 조건 추가. 첫 MLB 적응은 전체 프로 연차가 아닌 MLB 경험으로 판단 |
| 아웃·주자 상황 불일치 | 7회 2사 이후 남은 아웃 4개, 동점 만루 밀어내기 끝내기, 세이브 상황의 주자·아웃, 2사 도루 실패 결과 등을 일치시킴 |
| 본문과 변형의 다른 사건 | 팬 편지·사인회·포구·사구 부위·여행 수단·연속 안타 문맥을 선택지 및 결과와 맞춤 |
| 기록과 다른 확정 보상 | 실제 계약이 바뀌지 않는 콜업은 평가 요청으로, 수상 미집계 상태의 타이틀 획득은 경쟁·자신감으로 표현. 장기계약 중 연봉 재협상은 별도 성과 보상으로 변경 |
| 시간 경과 없는 군 복무 | 2년 복무 완료 및 병역 해결 특성 부여를 병역 계획 상담 및 계획 수립 특성으로 변경. 나이와 시즌이 그대로인 채 복무를 마쳤다고 하지 않음 |
| 판정 방식에 종속된 포수 훈련 | 프레이밍으로 판정을 바꾼다는 훈련을 포구·블로킹 기본기 훈련으로 변경 |
| 변형과 효과의 모순 | 장비 적응 실패로 약점이 크게 성장하던 효과 제거. 실제 역할 변경을 보장하지 않는 훈련 문구를 준비 과정으로 조정 |

`roles`, `minAge`, `duringRehab`, `once`를 이벤트 명세에 추가했다. 본문 전체를 읽고 의미를 검토한 뒤, 자동 검사는 명세의 도달 가능성과 회귀를 확인한다. 자동 검사만으로 모든 문장의 의미를 판정하는 것은 아니다.

저장 파일의 `eventRevision`이 이전 버전이면 최신 사건 본문으로 갱신한다. 포지션·리그·보직 등의 조건에 맞지 않는 대기 사건은 적합한 사건으로 교체하며 선수 기록은 보존한다. 현재 버전의 적합한 사건은 선택했던 본문 변형을 그대로 복원한다.

## UI/UX

- 시즌·프로 연차·리그·포지션·보직을 한 곳에서 확인하는 시즌 헤더.
- 모바일 하단 메뉴의 현재 위치 강조, 안전 영역 여백, 터치 크기 확보.
- 사건 태그/본문/번호가 붙은 선택지/확률과 효과 순서로 읽히는 이벤트 카드.
- 선택 중 시즌 전망과 계약은 펼쳐 볼 수 있게 접고, 결과 화면에서는 기본으로 펼침.
- 이벤트의 등장 이동 애니메이션을 제거하고 카드 시작점으로 스크롤해 상단 바에 제목이 가려지지 않도록 변경.
- 저장된 커리어 이어하기를 시작 화면 상단에서 강조.
- 계약 제안 위에 현재 구단·연봉·잔여 계약을 표시해 비교 지원.
- 기록실에서 리그별 필터와 최신/첫 시즌 정렬 지원.
- 시작 화면은 기존 sprite-gen GPT 해외 진출 이미지를 재사용. 새 이미지 다운로드를 추가하지 않고 기존 WebP를 활용한다.
