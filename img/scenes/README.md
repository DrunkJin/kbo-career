# Career illustrations

Generated with `sprite-gen gen --provider codex` through GPT on 2026-09-13,
using the user's authorized ChatGPT account. No reference images were supplied.
Art direction: airy casual pencil sketches, off-white paper, sky blue and mint
watercolor, sparse backgrounds and relaxed adult baseball players.

Seven everyday scenes: pitching, batting, clubhouse conversations, rehab planning,
fan letters, contract decisions and farewell. Two milestone scenes: championship
and overseas. Event IDs explicitly select appropriate scenes and respect position.
Setup follows the selected position; retirement shows farewell.

Each scene has 960 x 540 and `-small.webp` 480 x 270 variants, encoded as WebP
quality 81 after visual review. Small files range from 13,934 to 25,642 bytes.
Only rendered scenes are requested. Captions and alternative text are separate
from the artwork; failed images disappear without blocking game choices.
Original PNGs, prompts and generation reports are in ignored `artifacts/light-scenes/`.
